# Aplikasi Penghitung Pengeluaran CAT
## _Aplikasi ini adalah aplikasi pencatat keuangan sederhana yang membantu pengguna melacak pemasukan dan pengeluaran sehingga saldo tabungan selalu terpantau dengan jelas._

[![Build Status](https://travis-ci.org/joemccann/dillinger.svg?branch=master)](https://travis-ci.org/joemccann/dillinger)

# Fitur Aplikasi CAT

Dalam aplikasi ini memiliki beberapa fitur yang ada didalam aplikasi ini.

- Pencatatan pemasukan dan pengeluaran dengan nominal rupiah yang jelas dan kategori seperti makan, gaji, dan lainnya.
- Ringkasan total saldo, total pemasukan, dan total pengeluaran yang ditampilkan di halaman utama agar kondisi keuangan cepat terbaca.
- Riwayat transaksi lengkap beserta tanggal dan deskripsi sehingga memudahkan pengguna meninjau kebiasaan finansial dan melakukan evaluasi pengeluaran.
- ✨Magic ✨

## Manfaat Bagi Pengguna

Dengan memakai aplikasi ini, pengguna dapat mengontrol arus kas harian, bulanan, atau sesuai kebutuhan, sehingga lebih mudah menyusun anggaran dan menabung untuk tujuan tertentu. Aplikasi ini cocok untuk pelajar, karyawan, maupun siapa saja yang ingin mengatur keuangan pribadi secara rapi, praktis, dan terstruktur langsung dari smartphone.
